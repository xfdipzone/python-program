# InternVL3

**InternVL3**（书生·万象3.0）是由上海人工智能实验室推出的开源多模态大模型，采用原生多模态联合预训练范式，打破了传统图文分离的训练架构

该系列涵盖从端侧到百亿参数的全尺寸版本，不仅具备出色的细粒度视觉感知、长视频理解与工业级 OCR 能力，更在 GUI 智能体控制、3D 空间感知及复杂工具调用等实际应用场景中取得了突破性表现
