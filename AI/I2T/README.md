# 自动识别图像内容为自然语言文本 I2T (Image To Text)

**I2T** 是（Image To Text 图生文 / 图像到文本）的缩写，指利用计算机视觉（CV）与自然语言处理（NLP）跨模态融合技术，将图像内容直接 **翻译或理解** 为自然语言文本输出的跨模态人工智能技术

## Qwen2.5-VL

**Qwen2.5-VL** 是通义千问（Qwen）团队推出的新一代视觉语言大模型系列。它具备原生动态分辨率与 2D RoPE 架构，能够精准识别复杂文档图表、定位视觉元素并理解小时级长视频，高效实现图像与视频内容向文本及结构化数据的精准转化与智能推理

- [基于 Qwen2.5-VL 实现自动识别图像内容为自然语言文本](./Qwen2.5-VL/qwen2.5_vl_image_to_text.py)

  基于 Qwen2.5-VL 实现自动识别图像，并将识别的图像内容描述为自然语言文本

- [基于 Qwen2.5-VL 实现批量独立自动识别图像内容为自然语言文本](./Qwen2.5-VL/qwen2.5_vl_batch_image_to_text.py)

  基于 Qwen2.5-VL 实现批量独立自动识别图像，并将识别的多个图像内容分别描述为自然语言文本

- [基于 Qwen2.5-VL 实现自动识别多图像内容综合分析为自然语言文本](./Qwen2.5-VL/qwen2.5_vl_multi_image_to_text.py)

  基于 Qwen2.5-VL 实现自动识别多图像内容，并综合分析，将多图像内容描述为自然语言文本

## InternVL3

**InternVL3**（书生·万象3.0）是由上海人工智能实验室推出的开源多模态大模型，采用原生多模态联合预训练范式，打破了传统图文分离的训练架构

该系列涵盖从端侧到百亿参数的全尺寸版本，不仅具备出色的细粒度视觉感知、长视频理解与工业级 OCR 能力，更在 GUI 智能体控制、3D 空间感知及复杂工具调用等实际应用场景中取得了突破性表现
