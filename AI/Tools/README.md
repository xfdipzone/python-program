# Tools

AI 项目中常用的工具集合

## 工具列表

- [删除指定目录及其所有子目录](./delete_directory.py)

  删除项目中指定目录及其所有子目录，用于删除生成的临时文件等

- [Google Colab Driver 归档下载](./colab_download.py)

  将 Google Colab Driver 文件夹压缩为档案并下载到本地，支持多种压缩格式（默认为 ZIP）

- [Youtube 视频下载器](./youtube_video_downloader.py)

  根据用户提供的 Youtube 视频访问地址，将视频下载到本地，支持多种画质与保存格式（默认 1080p 与 mp4）
